# Sicherheit / Security

## Sicherheitslücken melden

Bitte melden Sie mögliche Sicherheitslücken in KLXM Studio **nicht** über öffentliche Issues, sondern vertraulich:

- **GitHub:** „Report a vulnerability“ im Reiter *Security* dieses Repositorys (Private Vulnerability Reporting), oder
- **E-Mail:** KLXM Crossmedia GmbH, <info@klxm.de> – Betreff „Security: KLXM Studio“.

Hilfreich sind: betroffene Version (`CMS_VERSION` in `app/bootstrap.php`), Beschreibung, Schritte zum Nachvollziehen
bzw. ein Proof of Concept und die mögliche Auswirkung. Bitte keine Tests gegen fremde Installationen und keine
echten personenbezogenen Daten verwenden.

Wir bestätigen den Eingang so bald wie möglich, prüfen die Meldung und stimmen Behebung und Veröffentlichung mit
Ihnen ab. Auf Wunsch nennen wir Sie im Changelog. Ein Bug-Bounty-Programm oder eine Vergütung gibt es nicht.

## Unterstützte Versionen

Sicherheitskorrekturen erscheinen für die jeweils aktuelle Version (neuester Release unter
[GitHub Releases](https://github.com/KLXM-Opensource/studio/releases)). Bitte aktualisieren Sie vor einer Meldung, wenn möglich.

---

**English:** Please report vulnerabilities privately – via GitHub's “Report a vulnerability” (Security tab) or by
e-mail to KLXM Crossmedia GmbH, <info@klxm.de> (subject “Security: KLXM Studio”) – not in public issues. Include the
affected version, a description, steps to reproduce and the impact. We will acknowledge and coordinate a fix and
disclosure with you. There is no bug bounty.
